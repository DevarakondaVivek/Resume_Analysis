# 🚀 AI-Powered Resume Analyzer

The **AI-Powered Resume Analyzer** is a full-stack platform designed to help job seekers optimize their applications for modern Applicant Tracking Systems (ATS). Built using the **Antigravity** framework, the app leverages **Gemini 3 Pro** to provide data-driven feedback on resume-to-job-description alignment.

### 🛠️ Key Features
* **ATS Scoring:** Generates a match percentage based on semantic analysis of your resume and a target job description.
* **Skill Gap Analysis:** Pinpoints missing keywords and technical skills recruiters are looking for.
* **AI-Driven Suggestions:** Offers bullet-point optimization to improve the impact of your work history.
* **Persistent History:** Uses **Firebase** to securely save and track resume iterations.

### 🏗️ Architecture
The project follows a **Three-Layer Architecture** (Directives, Orchestration, and Execution) to maintain a clean, scalable codebase. It was developed using a "Planning, Testing, and Deploying" methodology, ensuring all features are fully functional before going live on **Firebase Hosting**.

### 💻 Tech Stack
* **Frontend:** Next.js / Tailwind CSS
* **Backend:** Firebase Firestore & Authentication
* **AI Engine:** Google Gemini 3 Pro
* **Protocol:** Model Context Protocol (MCP) for service integration
